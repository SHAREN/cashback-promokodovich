# Развёртывание и восстановление

## Веб-часть

Исходники PWA находятся в этом репозитории. В рабочей системе статические файлы копируются в:

`/var/www/webuirenat-fallback/cashback/`

Основной Nginx уже раздаёт `/var/www/webuirenat-fallback`, поэтому отдельный веб-сервис для PWA не нужен.

После изменений JavaScript/CSS/Service Worker:

1. проверить синтаксис JavaScript;
2. скопировать изменённые статические файлы в рабочий каталог;
3. увеличить имя/версию Cache Storage в `sw.js`, если требуется принудительно обновить оболочку;
4. открыть PWA один раз с интернетом, чтобы новый Service Worker активировался.

## Hermes

Живые файлы:

- `/home/renat/.hermes/cashback-promokodovich/cashback_promokodovich.py`
- `/home/renat/.hermes/skills/cashback-promokodovich/SKILL.md`

В `hermes/` этого репозитория лежит снимок этих файлов для истории и восстановления.

SQLite-база намеренно не коммитится. При восстановлении код создаёт схему автоматически, но сами пользовательские данные нужно восстанавливать из отдельной резервной копии либо заносить заново.

## Проверка после изменений

Проверить:

- PWA открывается по `https://webuirenat.duckdns.org/cashback/`;
- `data.json` доступен;
- текущие банки и категории отображаются;
- после одного онлайн-открытия приложение запускается в авиарежиме;
- свежие данные после изменения Hermes появляются при следующем онлайн-открытии.

## Важное решение интерфейса

Функция копирования текста/эмодзи для Mir Pay была удалена. В текущем интерфейсе нет кнопки «Скопировать» и нет скрытой логики формирования такого текста.
