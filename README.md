# Cashback Промокодович

Личный модуль для хранения и быстрого просмотра ежемесячных банковских кэшбэков.

## Что входит

- **Hermes + SQLite** — источник истины по банкам, месяцам и категориям.
- **PWA** — мобильная страница с текущими кэшбэками.
- **Офлайн-режим** — после первого открытия последняя версия остаётся на телефоне и показывается сразу, а свежие данные подтягиваются уже после запуска.
- **Hermes-задачи** — контроль незаполненных банков и напоминание перед новым месяцем.

Рабочая PWA:

`https://webuirenat.duckdns.org/cashback/`

## Текущая архитектура

Источник истины находится в живом Hermes:

- CLI: `/home/renat/.hermes/cashback-promokodovich/cashback_promokodovich.py`
- SQLite: `/home/renat/.hermes/cashback-promokodovich/cashback.sqlite3`
- Skill: `/home/renat/.hermes/skills/cashback-promokodovich/SKILL.md`

Веб-часть развёрнута в:

- `/var/www/webuirenat-fallback/cashback/`

При изменении данных через CLI Hermes автоматически формирует:

- `/var/www/webuirenat-fallback/cashback/data.json`

PWA читает этот JSON и хранит последнюю успешную копию локально.

## Как работает офлайн

При запуске приложение сначала показывает сохранённые данные из локального хранилища. Оно не ждёт сеть. После этого, если интернет доступен, запрашивается свежий `data.json`.

Service Worker отдельно кэширует HTML, CSS, JavaScript, manifest и иконки. Поэтому установленная PWA должна открываться после закрытия приложения и перезагрузки телефона без подключения к интернету, пока пользователь сам не очистит данные приложения/браузера.

## Интерфейс

Интерфейс намеренно простой:

- текущий месяц;
- карточка каждого активного банка;
- процент и название каждой категории;
- пометка, если банк ещё не заполнен;
- время последнего обновления.

**Кнопки копирования и генерации короткого текста для Mir Pay сейчас нет. Она была удалена по решению пользователя и не должна возвращаться без отдельного запроса.**

## Репозиторий и данные

В Git храним код и документацию, но **не храним живую SQLite-базу, персональные данные и runtime-секреты**.

Каталог `hermes/` содержит снимок текущего кода Hermes и Skill для восстановления/истории. Живой Hermes остаётся рабочим источником.
